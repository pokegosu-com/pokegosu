# Agent instructions

Follow [CONTRIBUTING.md](CONTRIBUTING.md). The rules below add to it.

## Rules

- Read the `AGENTS.md` of the app you are working in, where there is one.
- For anything a person sees or reads in an app, follow [DESIGN.md](DESIGN.md).
- Comments often record why code is the way it is. Take them into account when changing it.
- Comments say why, not what.
- After a change, check whether any doc needs updating.
- Work on a branch and open a pull request to `main`.
- On a branch under review, add commits. Do not amend, squash or force-push.
- Write prose unwrapped, one paragraph per line, in pull requests and Markdown.

## Ask first

- Never push a tag: a tag is a release.
